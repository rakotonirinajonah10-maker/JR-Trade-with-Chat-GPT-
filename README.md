# JR Trade V2.3

Prototype Web3 / crypto exchange en mode démo.

## V2.3 — Dashboard + Wallet avancé
- Valeur totale du portefeuille calculée depuis Supabase
- Liquidités USD + valeur crypto
- Variation estimée sur 24 h selon les actifs détenus
- Allocation par crypto
- Quantités et valeurs par actif
- Dashboard et Wallet synchronisés avec Supabase
- RLS conservée

## Installation
Remplace les fichiers du dépôt GitHub par ceux de cette archive, puis commit directement sur `main`.

**Important :** `supabase-config.js` contient uniquement la Project URL et la Publishable key. Ne mets jamais une clé `sb_secret_` dans le navigateur.

Le trading reste en mode démo et ne réalise aucune transaction blockchain réelle.
